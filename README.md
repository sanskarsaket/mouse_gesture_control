# 🖱️ Mouse Gesture Control using OpenCV

Control your mouse using hand gestures detected through a webcam! This project leverages **OpenCV** and **Mediapipe** to recognize hand movements and translate them into mouse operations like movement, clicking, and scrolling.

## 📽️ Demo

![demo-gif](demo.gif) <!-- Replace with your actual demo if available -->

## ✨ Features

- Move the cursor using hand position
- Left click using finger pinch
- Right click with a specific hand gesture
- Scroll up/down with vertical hand movement
- Real-time gesture tracking using webcam

## 🛠️ Tech Stack

- Python
- OpenCV
- Mediapipe
- PyAutoGUI

## 🖥️ Requirements

- Python 3.7+
- Webcam
